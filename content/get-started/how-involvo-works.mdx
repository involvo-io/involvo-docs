# How INVOLVO works

INVOLVO lists events that other people run. Knowing how a listing got here tells you how much to trust its details — and who to ask when something is unclear.

## Two ways an event gets listed

**The organization posts its own event.** Someone who is part of the organization running the event adds it, and it appears straight away. They can update it as things change.

**Someone shares an event they found.** Anyone can add an event they did not organize — one they saw on Instagram, or heard about from a friend. These are checked by INVOLVO before they appear. If the organization behind the event is not on INVOLVO yet, a page is created for it.

The second path is what makes INVOLVO useful. It is also the reason some listings are maintained by nobody.

## Claimed and unclaimed

An organization page is **claimed** when someone from that organization has access to it on INVOLVO and can manage it.

It is **unclaimed** when the page exists — usually because someone shared one of their events — but nobody from the organization has access yet. Nobody there is updating it, and they may not know the page exists.

Some organizations also carry a **verified** badge. Verification is granted by INVOLVO; it is not something an organization switches on itself.

You can see which of these applies on any organization's page. See [Organization profiles and badges](/organizations/profiles-and-badges).

## What this means when you are deciding whether to go

For an event posted by its own organization, the page is as current as the organizer keeps it.

For an unclaimed event, the details are a snapshot of what was true when someone added them. That is usually fine, and it goes out of date rarely — but it does happen. A deadline can pass, a venue can move, an event can be called off without the listing changing.

So, before anything that costs you money, travel or a missed deadline, confirm it against the organizer directly. Every event page shows who is running it.

How you reach them from there depends on the listing. An event posted by its own organization links straight out to that organization's site, page or registration form. On an event added by someone else, those outward links are hidden until you open them, which uses Impact Stars — see [Earning and spending Stars](/platform/earning-and-spending-stars). You can always search for the organizer yourself instead.

If something already looks wrong, see [When something looks wrong](/participants/participating/troubleshooting).

## INVOLVO is not the organizer

Whichever way an event got here, INVOLVO is not running it. Questions about the program, the venue, the cost or who gets selected go to the organizer. See [What is INVOLVO?](/get-started)
