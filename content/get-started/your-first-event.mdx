# Your first event, start to finish

This is a map of the usual path from finding an event to turning up at it, with a link to the detail for each step.

It is a **typical** journey, not a required one. Events differ: some ask you to apply and wait, some let you register on the spot, some are invitation-only, and some you can simply walk into. Not every step below applies to every event.

## The usual path

1. **Find something.** Browse the feed or the calendar, and narrow it down to what fits you — [The feed and the calendar](/participants/discovering/feed-and-calendar), [Filters](/participants/discovering/filters).

2. **Read the event page.** Check the date, the location, who is running it, and how you are meant to sign up — [Reading an event page](/participants/discovering/event-pages).

3. **Save it, so you do not lose it.** Especially useful when registration has not opened yet — [Saving events and reminders](/participants/discovering/saving-events).

4. **Get in.** Apply, register, or follow the organizer's own registration link — whichever this event uses — [How you get into an event](/participants/applying/how-you-get-in).

5. **Turn up and check in.** Checking in also shows you who else came — [Check in and check out](/participants/participating/check-in).

6. **Say how it went.** Feedback goes to the organizer — [After the event: feedback](/participants/participating/feedback).

## Before you start

You do not need an account to browse, but you do need one for most of the steps above. See [Do I need an account?](/get-started/accounts)
